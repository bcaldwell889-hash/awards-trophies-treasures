# Awards, Trophies & Treasures

VS Code-ready storefront prototype built with React and Vite.

## Run locally

1. Open this folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Current features

- Responsive industrial/professional storefront design
- Product categories and catalog filtering
- Sample product cards and pricing
- Working shopping cart with quantities and totals
- Demonstration checkout and personalization notes
- Checkout is intentionally not connected to a payment account yet
